Release notes

What changed in each version of MiniHost. The newest is at the top.

Version 1.0.0 26 November 2026Latest

  • First release. Files in any browser with resumable uploads, previews, editing and share links; a network drive (WebDAV) and SFTP; accounts with roles and 6-digit codes for admins.
  • Websites from four ready-made designs or your own zip, and a Netflix-style library of films, shows and music with resume, subtitles, playable copies and smart-TV streaming.
  • Home only or Anywhere, with Tailscale and Cloudflare chosen per service; alerts through ntfy, a Healthchecks.io gone-offline check, a one-tap health check and speed test, and encrypted backups to Google Drive.
  • Server Mode, an illustrated set-up walkthrough, a searchable help centre and four looks.

Checking your download

The file for version 1.0.0 is called MiniHost.apk. It is 30.7 MB (30,713,923 bytes). Its SHA-256 checksum is:

554174edf837920967fc3c05003ccb1e1a1e15aeaa66a271b4f0c1eb7fd6cc13

On Windows, run certutil -hashfile MiniHost.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
