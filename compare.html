What MiniHost does not do

MiniHost is a home server for files, websites and media. It does not run PHP, databases, mail, FTP or the dozens of other server types Servers Ultimate lists, and it is not on Google Play, so it does not update itself.

Where the others do more

Servers Ultimate lists over 60 kinds of server and 18 network tools. SHTTPS offers screen sharing, a REST API and runs on Android TV. Both install and update from Google Play.
